# Documents

Use this directory only for public project documents, plans, and synthetic examples. Files here may
be tracked by Git. Never store personal resumes, job descriptions, fact snapshots, generated
resumes, or other personal data here.

The Prompt-first workflow asks the user to select exact input files; the CLI has no default resume
or job-description paths. Managed inputs and outputs belong under the Git-ignored `private_data/`
directory. Keep test content synthetic and use reserved example addresses and phone numbers only.

## Available Documents

- [Prompt-Route User Guide](prompt_route_user_guide.md): Comprehensive, step-by-step user guide for the Phase 1 Prompt-first local workflow.
- [Resume Templates](templates/README.md): Collection of popular, ATS-compliant single-column DOCX resume templates (`classic`, `modern`, `compact`).
- [Production-Grade Resume Tailor Agent Design Plan](resume_tailor_agent_design.md): Detailed multi-phase engineering plan and architectural specification.
