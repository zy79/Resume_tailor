# Project Skills

Add each reusable, on-demand skill in its own directory:

```text
.agents/skills/<skill-name>/SKILL.md
```

Each `SKILL.md` should use frontmatter with a matching `name` and a concise `description` that explains when the skill applies. Keep task-specific procedures and supporting assets in that skill directory. Put rules that apply to every task in the root `AGENTS.md` instead.
